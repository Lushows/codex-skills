# Traducir característica a beneficio

## La regla

Una característica es un hecho del producto. Un beneficio es un cambio en la vida del cliente.
El cliente no compra hechos: compra cambios.

```
característica → "¿y eso qué significa para mí?" → beneficio
                 (repetir hasta que la respuesta duela o alivie)
```

A eso se le llama **encadenar el "¿y qué?"**. Si paras en el primer paso, te quedas en una ficha
técnica. Hay que bajar dos o tres escalones.

## Ejemplo del encadenamiento

```
"Batería de 2.000 mAh"
  ¿y qué? → dura 8 horas sin cargar
  ¿y qué? → te alcanza toda la jornada de trabajo
  ¿y qué? → no tienes que buscar enchufe en la mitad del turno   ← ESTE es el beneficio
```

## El formato que convierte: característica + beneficio juntos

No borres la característica. Úsala como **prueba** del beneficio.

```
❌ "Acero inoxidable 304"
❌ "No se oxida"
✅ "No se oxida ni suelta sabor a metal — es acero 304, el mismo de las cocinas industriales"
```

La característica sola aburre. El beneficio solo suena a promesa vacía. Juntos, el beneficio
convence y la característica lo respalda.

## Dónde va cada cosa en la página

| Sección | Qué usar |
|---|---|
| Hook / primeras 3 líneas | dolor (`213`) + beneficio principal |
| Bloque de valor | 3-4 beneficios, cada uno con su característica de respaldo |
| Ficha técnica (abajo) | todas las características, sin adorno |
| Preguntas frecuentes | características que responden objeciones |

La ficha técnica sí debe existir: hay compradores que la buscan para confiar. Pero va **abajo**,
después de haber vendido el cambio.

## Errores comunes

| Error | Ejemplo | Corrección |
|---|---|---|
| Beneficio genérico | "mejora tu vida" | "dejas de lavar 3 ollas cada noche" |
| Beneficio no verificable | "te hace más feliz" | algo que el cliente pueda comprobar el día 1 |
| Traducción a medias | "dura 8 horas" | "te alcanza toda la jornada" |
| Solo beneficio, cero prueba | "no se oxida" | agrega la característica que lo sostiene |
| Exageración | "el mejor del mundo" | específico y comprobable (`07`) |

## Prueba rápida

Lee tu copy en voz alta y pregunta después de cada frase: **"¿y eso qué me da a mí?"** Si la frase
no sobrevive esa pregunta tres veces seguidas, está en el nivel de característica. Baja un escalón.
