# Glosario del ecommerce y el dropshipping

> Define cada término la primera vez que aparezca en una conversación. El usuario aprende mientras
> construye.

## Dinero y rentabilidad

| Término | Qué es | Trampa habitual |
|---|---|---|
| **Ticket / AOV** | Lo que paga el cliente en una compra (Average Order Value) | Confundirlo con el precio del producto: el bundle y el upsell lo suben |
| **Margen bruto** | Ticket menos costos directos del pedido | Olvidar el flete y los pedidos fallidos |
| **Margen de contribución** | Lo que queda para pagar CAC y gastos fijos | Se confunde con margen bruto |
| **Techo de CAC** | Lo máximo que puedes pagar por una venta sin perder | El número más importante del negocio, y casi nadie lo calcula |
| **CAC** | Costo de adquirir un cliente que **paga** | Dividir por pedidos generados en vez de cobrados |
| **CPA** | Costo por adquisición que reporta la plataforma | No incluye los que no se entregaron en COD |
| **ROAS** | Ingreso ÷ inversión publicitaria | Un ROAS "bueno" depende del margen; solo no dice nada |
| **ROAS de equilibrio** | ROAS bajo el cual pierdes plata | Es tu línea de flotación real |
| **LTV** | Valor total de un cliente en el tiempo | En dropshipping suele ser ≈ 1 compra; no te engañes |
| **Múltiplo** | Ticket ÷ costo puesto en bodega | La regla de "3x" ya no aplica. Ver `42` |
| **Punto de equilibrio** | Unidades o ingreso donde dejas de perder | Ver `225` |
| **Flujo de caja** | Cuándo entra y sale la plata | Puedes ser rentable y quebrar igual. Ver `234` |
| **Velocidad de rotación de caja** | Cuántas veces reinviertes el mismo dinero | La variable clave con capital chico. Ver `32` |

## Tráfico y anuncios

| Término | Qué es |
|---|---|
| **CPM** | Costo por mil impresiones. Sube 20-80% en Q4 |
| **CPC** | Costo por clic |
| **CTR** | Porcentaje de quienes ven el anuncio y hacen clic |
| **CVR** | Porcentaje de quienes entran a la página y compran |
| **Hook** | Los primeros 3 segundos del video. Decide si te ven o te pasan |
| **Ángulo** | El motivo por el que alguien querría el producto. No es el producto. Ver `250` |
| **Creativo** | La pieza (video o imagen) del anuncio |
| **Fatiga creativa** | Cuando el mismo anuncio deja de funcionar por sobreexposición |
| **UGC** | Contenido que parece hecho por un usuario, no por una marca |
| **Advantage+ / ASC** | Campañas automatizadas de Meta que eligen público solas |
| **Píxel** | Código que reporta a la plataforma lo que pasa en tu tienda |
| **CAPI** | API de conversiones: reporta desde el servidor, no desde el navegador |
| **Retargeting** | Anunciar a quien ya te visitó |
| **Escalar** | Subir presupuesto sin que se dispare el CAC |
| **Biblioteca de anuncios** | Archivo público de Meta con todos los anuncios activos. Ver `81` |

## Producto y proveedor

| Término | Qué es |
|---|---|
| **Producto ganador** | El que deja margen positivo **después** del CAC |
| **Saturación** | Tantos vendiéndolo que el CPM sube y el margen desaparece |
| **MOQ** | Cantidad mínima que el proveedor acepta vender (Minimum Order Quantity) |
| **FOB** | Precio con la mercancía puesta en el puerto de origen |
| **EXW** | Precio en la fábrica; tú pagas todo lo demás |
| **DDP** | El proveedor entrega con aranceles pagados en destino |
| **DDU / DAP** | Llega sin aranceles pagados: los cobra el courier al cliente. Peligroso |
| **Agente de sourcing** | Intermediario en China que consigue, inspecciona y despacha. Ver `116` |
| **Private label / marca blanca** | El mismo producto con tu marca impresa |
| **1688** | El AliExpress interno de China: más barato, en chino, sin envío internacional |
| **Muestra** | Unidad de prueba que pides antes de vender. No opcional |

## Logística y aduana

| Término | Qué es |
|---|---|
| **De minimis** | Umbral de valor bajo el cual no se cobraba arancel. Se acabó en EE.UU., UE y México |
| **Arancel** | Impuesto a la importación, porcentaje sobre el valor |
| **Fracción arancelaria** | El código que clasifica tu producto y define cuánto paga |
| **Courier / mensajería** | Régimen simplificado para paquetes pequeños |
| **3PL** | Empresa que almacena y despacha por ti (Third Party Logistics) |
| **Última milla** | El tramo final, del centro de distribución a la puerta |
| **Tasa de entrega** | Porcentaje de pedidos despachados que efectivamente se entregan y cobran |
| **Logística inversa** | La devolución del paquete no entregado |
| **Tránsito** | Días entre el despacho y la llegada |

## Pago y cobro

| Término | Qué es |
|---|---|
| **COD / contraentrega** | El cliente paga al recibir. Estándar en LatAm |
| **Prepago** | El cliente paga en la página antes de despachar |
| **MSI** | Meses sin intereses. Mecanismo de compra dominante en México. Ver `195` |
| **Pasarela** | El servicio que procesa el pago (Stripe, MercadoPago, Wompi) |
| **Contracargo** | El cliente reclama a su banco y le devuelven el dinero. Ver `282` |
| **Order bump** | Oferta pequeña añadida en el checkout |
| **Upsell** | Oferta de más valor después de la compra |
| **Carrito abandonado** | Quien llegó al checkout y no terminó |

## Impuestos internacionales

| Término | Qué es |
|---|---|
| **IOSS** | Ventanilla única de la UE para vender bienes importados bajo €150 |
| **Intermediario IOSS** | Representante establecido en la UE, obligatorio si no estás en la UE |
| **IVA / IGV / VAT** | Impuesto al consumo. Cambia de nombre por país |
| **TLC** | Tratado de libre comercio. Define si tu origen paga arancel preferencial |
