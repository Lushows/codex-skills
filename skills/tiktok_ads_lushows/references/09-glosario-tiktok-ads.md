# 09 — Glosario TikTok Ads

Lee este módulo cuando te topes con una sigla que no entiendes en el Ads Manager o en esta skill, o como repaso rápido antes de hablar con un cliente y no quedar mal. TikTok mezcla siglas de performance (heredadas de Meta/Google) con jerga propia del creativo (hook rate, thumbstop) y del comercio (GMV, VSA). Aquí están traducidas al español llano, con la fórmula cuando aplica. No memorices: vuelve aquí cuando lo necesites.

## Métricas de costo y rendimiento

| Sigla | Nombre | Qué es / fórmula |
|---|---|---|
| **CPM** | Costo por mil impresiones | Lo que pagas por 1.000 vistas del anuncio. Resultado de tu creativo, no un precio fijo (ver 01) |
| **CTR** | Click-Through Rate | % de quienes ven y hacen clic. Clics ÷ impresiones × 100 |
| **CVR** | Conversion Rate | % de quienes hacen clic y convierten. Conversiones ÷ clics × 100 |
| **CPC** | Costo por clic | Gasto ÷ clics |
| **CPA** | Costo por adquisición | Gasto ÷ conversiones. La métrica reina de leads/ventas (ver 60) |
| **CPL** | Costo por lead | CPA pero para leads (ver 54) |
| **ROAS** | Return on Ad Spend | Ingresos ÷ gasto en pauta. ROAS 3 = $3 por cada $1 (ver 64) |
| **AOV** | Average Order Value | Ticket promedio. Ingresos ÷ número de pedidos |
| **Frequency** | Frecuencia | Veces promedio que una persona vio tu anuncio. Alta = fatiga (ver 39) |

## Métricas de creativo (las propias de TikTok)

| Término | Qué mide | Por qué importa |
|---|---|---|
| **Thumbstop / Thumbstop rate** | % que frena el dedo y no te salta en los primeros segundos | Tu hook funciona o no (ver 37) |
| **Hook rate** | % que sigue viendo tras los primeros ~3s (a veces vistas de 3s ÷ impresiones) | Lo más importante del creativo (ver 49) |
| **Hold rate** | % que retiene hasta cierto punto del video | Si el cuerpo del video aguanta (ver 31) |
| **2-second / 6-second view rate** | % que vio al menos 2s / 6s | Señales de retención que mueven el CPM (ver 49) |
| **Completion rate** | % que vio el video completo | Para videos cortos, señal de enganche |
| **Engagement** | Likes, comentarios, shares, saves | Prueba social que ayuda en la subasta (ver 34) |

## Formatos, campañas y comercio

| Término | Qué es |
|---|---|
| **For You / FYP** | El feed principal personalizado; donde vive el descubrimiento (ver 02) |
| **In-Feed Ad** | Anuncio de video entre el contenido orgánico del FYP |
| **Spark Ad** | Impulsar un post orgánico conservando likes/comentarios y la señal social; el que más rinde (ver 34) |
| **TopView / Top Feed** | Anuncio premium al abrir la app |
| **Photo / Carousel Ads** | Anuncios de imágenes deslizables sin video (ver 35) |
| **Smart+** | La campaña automatizada de TikTok (Web/Catalog/App/Lead); equivale a Advantage+/PMax (ver 12, 90) |
| **GMV Max** | Campaña automatizada de TikTok Shop que maximiza ventas (ver 52) |
| **GMV** | Gross Merchandise Value: valor total de mercancía vendida vía Shop |
| **VSA** | Video Shopping Ads: video con producto comprable del catálogo (ver 51) |
| **TTCM / Creator Marketplace** | Plataforma para contratar creators (ver 32) |
| **Partnership Ads** | Anuncios en colaboración formal con un creator |
| **Search Ads** | Anuncios en el buscador interno de TikTok; capturan intención dentro de la app (ver 11) |
| **Symphony** | Suite de IA creativa de TikTok: guiones, avatares, doblaje/traducción (ver 91) |
| **TikTok One** | Punto de entrada unificado a creators, Symphony y herramientas para marcas |
| **Creative Center** | Biblioteca pública de tendencias y anuncios para inspirarte/espiar (ver 94) |
| **Commercial Music Library** | Catálogo de música licenciada para usar en ads (ver 08) |

## Medición, públicos y subasta

| Término | Qué es |
|---|---|
| **Pixel** | Sensor de conversiones en tu web (ver 05) |
| **Events API (EAPI)** | Envío de eventos server-side, esquiva pérdidas de iOS; el CAPI de TikTok (ver 06) |
| **event_id** | ID único para deduplicar Pixel + Events API (ver 05) |
| **EMQ** | Event Matching Quality: qué tan bien TikTok identifica al usuario del evento (ver 06) |
| **`ttclid`** | Click ID de TikTok; conecta el clic con la conversión, aun por WhatsApp. Equivale a `ctwa_clid` (Meta) / OCI (Google) (ver 06) |
| **SKAN / SKAdNetwork** | Sistema agregado de Apple para medir conversiones en iOS (ver 06) |
| **Atribución 7d-click / 1d-view** | Ventana default: cuenta conversiones hasta 7 días tras clic, 1 día tras vista (ver 16) |
| **Lookalike** | Público que se parece a tus clientes (ver 22) |
| **Custom Audience** | Público propio (visitantes, clientes, engagers) (ver 21) |
| **Learning Phase** | Fase de aprendizaje del algoritmo antes de estabilizar (ver 13) |
| **Bid / puja** | Lo que ofreces pagar por resultado en la subasta (ver 15) |
| **Cost Cap** | Tope de costo por conversión que le pones a la puja (ver 74) |

## Términos de negocio y atribución

| Término | Qué es |
|---|---|
| **Efecto demanda / "TikTok made me buy it"** | Ver algo en TikTok y comprarlo después por otro canal (Google, directo). Hace que TikTok parezca peor de lo que es (ver 03) |
| **Incrementalidad** | Las ventas extra que SÍ causó la pauta (no las que igual ocurrían). Se mide apagando/encendiendo (ver 57) |
| **UGC** | User-Generated Content: video tipo "persona real con celular", el formato que rinde (ver 32) |
| **Ban EE.UU.** | Restricción política en Estados Unidos; NO afecta la pauta en LatAm |

## Errores comunes — blacklist

- **Confundir CPM con lo que "pagas por anuncio".** El CPM es resultado del creativo, no un precio que pones. Fix: baja el CPM mejorando el video (ver 01).
- **Mirar CTR y creer que mides ventas.** Clics no son plata. Fix: optimiza y juzga por CPA/ROAS (ver 60).
- **Ignorar thumbstop y hook rate.** Son la causa raíz del costo. Fix: léelos antes que el CPA (ver 49).
- **Creer que GMV = ganancia.** GMV es venta bruta, no utilidad. Fix: descuenta costo, comisión y pauta (ver 52, 64).
- **Usar ROAS sin contar pérdida de iOS.** El ROAS del panel subreporta. Fix: cruza con Events API y backend (ver 64).
- **Confundir `ttclid` con un dato opcional.** Es lo que cierra el lazo hasta WhatsApp. Fix: propágalo siempre (ver 06).
- **Memorizar siglas sin entender la fórmula.** Fix: vuelve a esta tabla cuando dudes; piensa en la causa, no la sigla.
