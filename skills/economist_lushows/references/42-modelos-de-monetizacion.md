# 42 — Modelos de monetización

Cómo cobras define tu negocio tanto como qué vendes. Este módulo te ayuda a elegir el modelo de ingresos que mejor encaja con tu producto, tu cliente y tu flujo de caja — antes de fijar el precio (eso es el módulo 57).

## Primero: modelo de monetización ≠ precio
- **Modelo de monetización** = la *estructura* de cómo entra el dinero (una vez, mensual, por comisión, etc.).
- **Precio** = el *número* que cobras dentro de esa estructura (ver 57).
- Puedes cambiar el precio en una tarde. Cambiar el modelo es casi refundar el negocio. Por eso elegir bien aquí ahorra años.

## Los 8 modelos base

### 1. Pago único (one-time)
El cliente paga una vez y se lleva el producto/servicio. Lo clásico: tienda, restaurante, mueble, curso suelto.
- **A favor:** simple de entender, cobras todo de golpe (buen flujo de caja inmediato), nada de gestión de cobros recurrentes.
- **En contra:** cada mes empiezas de cero (no acumulas ingreso recurrente), dependes mucho de captar clientes nuevos.
- **Encaja cuando:** la necesidad es puntual o de baja frecuencia, o el ticket es alto.

### 2. Suscripción (recurrente)
El cliente paga un monto fijo cada periodo (mes/año) a cambio de acceso continuo. Software, membresías, "club de café", caja mensual de productos.
- **A favor:** ingreso predecible (MRR — *Monthly Recurring Revenue*, ingreso recurrente mensual), valor de vida del cliente alto (LTV, ver 52), valoración más alta del negocio.
- **En contra:** el cliente puede irse (*churn* = tasa de cancelación); debes entregar valor *cada* mes o se va. Construye despacio.
- **Encaja cuando:** entregas valor continuo y repetido (no algo que se usa una vez).

### 3. Freemium
Una versión gratis para siempre + una de pago con más funciones/límites. El gratis es marketing; un % pequeño convierte a pago.
- **A favor:** captación masiva a costo bajo, el producto se prueba solo.
- **En contra:** tasas de conversión bajas (orientativo: 1–5% de gratis a pago; verifica el tuyo, no lo asumas — ver 21), y los usuarios gratis cuestan dinero (soporte, servidores).
- **Encaja cuando:** el costo de servir a un usuario gratis es muy bajo y el producto mejora al tener más usuarios.

### 4. Transaccional / comisión
Cobras un % o monto fijo por cada transacción que facilitas. Pasarelas de pago, agencias por venta, intermediarios.
- **A favor:** alineas tu ingreso con el éxito del cliente (ganas cuando él gana), escala con el volumen.
- **En contra:** ingreso variable, dependes del volumen de otros, márgenes por transacción suelen ser finos.
- **Encaja cuando:** facilitas un movimiento de dinero o valor entre partes.

### 5. Marketplace
Conectas oferta y demanda y cobras comisión a uno o ambos lados (Uber, Airbnb, una plataforma local de domicilios).
- **A favor:** no produces inventario, escala fuerte si logras masa crítica.
- **En contra:** el "problema del huevo y la gallina" (sin oferta no hay demanda y viceversa), inversión grande para arrancar los dos lados.
- **Encaja cuando:** hay muchos compradores y muchos vendedores fragmentados que no se encuentran fácil.

### 6. Licenciamiento
Cobras por el derecho a usar tu propiedad intelectual (marca, software, patente, contenido). Franquicias, *white-label*, royalties.
- **A favor:** ingreso sin producir cada unidad, escala con poco costo marginal.
- **En contra:** requiere algo valioso y protegible; control limitado sobre cómo lo usan.
- **Encaja cuando:** tienes IP, marca o tecnología que otros quieren replicar.

### 7. Publicidad
El producto es gratis para el usuario; cobras a anunciantes por su atención. Medios, apps con tráfico alto.
- **A favor:** gratis baja la barrera de entrada, escala con la audiencia.
- **En contra:** necesitas **muchísimo** tráfico para que rinda; el usuario no es el cliente (el anunciante sí), y eso genera tensiones.
- **Encaja cuando:** ya tienes o puedes construir una audiencia grande y comprometida.

### 8. Por uso (pay-as-you-go / consumo)
Cobras según cuánto consume el cliente. Servicios en la nube, energía, datos, "pago por minuto/llamada/GB".
- **A favor:** justo y fácil de adoptar (pagas lo que usas), crece con el cliente.
- **En contra:** ingreso impredecible, factura sorpresa puede asustar al cliente.
- **Encaja cuando:** el consumo varía mucho entre clientes y puedes medirlo bien.

## Tabla comparativa rápida

| Modelo | Predictibilidad ingreso | Esfuerzo de arranque | Mejor para | Riesgo principal |
|---|---|---|---|---|
| Pago único | Baja | Bajo | Necesidad puntual / ticket alto | Captar siempre nuevos |
| Suscripción | Alta | Medio | Valor continuo | Churn |
| Freemium | Media | Medio-alto | Producto que se prueba solo | Conversión baja |
| Transaccional | Media | Medio | Facilitar transacciones | Volumen ajeno |
| Marketplace | Media | Alto | Oferta/demanda fragmentada | Huevo y gallina |

| Publicidad | Baja-media | Alto | Audiencia masiva | Necesita mucho tráfico |
| Por uso | Baja | Medio | Consumo variable | Factura impredecible |

## Puedes (y deberías) combinar modelos
Pocos negocios usan uno solo. Ejemplos de mezclas comunes:
- **Suscripción + por uso:** plan base mensual + cargo por consumo extra.
- **Freemium + suscripción + publicidad:** gratis con anuncios, pago quita anuncios y abre funciones.
- **Pago único + suscripción:** vendes el equipo una vez y cobras mantenimiento mensual.

## Ejemplo numérico (cifras 100% ilustrativas, no son datos de mercado)
Imagina un servicio que puedes vender de dos formas. Tu costo de servir a un cliente es ~$10.000/mes.

**Opción A — Pago único:** cobras $300.000 una vez.
- Si captas 20 clientes/mes → $6.000.000 ese mes. Pero el mes siguiente vuelves a depender de captar 20 nuevos.

**Opción B — Suscripción:** cobras $40.000/mes.
- Margen por cliente: $40.000 − $10.000 = $30.000/mes.
- Si cada cliente se queda en promedio 18 meses → LTV ≈ $40.000 × 18 = $720.000 (ver 52 para LTV con churn).
- Con 20 clientes nuevos/mes y poca cancelación, en el mes 6 tendrías ~110 clientes activos pagando → ~$4.400.000 *recurrentes*, sin partir de cero.

**Lectura:** A da más caja *hoy*; B construye un activo que vale más con el tiempo. La decisión depende de si necesitas efectivo ya (ver 55 sobre flujo de caja) o estás construyendo valor a largo plazo. No hay respuesta universal — depende de tu situación.

> Recordatorio: tasas de impuestos sobre suscripciones, facturación recurrente y reglas de cobro automático **varían por país**. Antes de implementar cobro recurrente, verifica las reglas vigentes de tu país/ciudad (IVA, facturación electrónica, débito automático permitido).

## Cómo elegir: 4 preguntas
1. **¿Con qué frecuencia el cliente obtiene valor?** Continuo → suscripción/uso. Puntual → pago único.
2. **¿Necesitas caja ya o construyes a largo plazo?** Caja ya → pago único (ver 55). Largo plazo → recurrente.
3. **¿Tu producto mejora con más usuarios o se prueba solo?** Sí → considera freemium/marketplace/publicidad.
4. **¿Tienes algo replicable y protegible (marca, IP, tecnología)?** Sí → licenciamiento es opción.

## Errores comunes
- **Copiar el modelo del competidor sin pensar** si tu estructura de costos o tu cliente son distintos.
- **Forzar suscripción** donde el valor es puntual (el cliente cancela al segundo mes y odia la marca).
- **Apostar todo a publicidad** sin tener la audiencia masiva que el modelo exige.
- **Lanzar freemium sin saber cuánto te cuesta el usuario gratis** ni tu conversión real (ver 21 para medirlo).
- **Confundir modelo con precio:** bajar el precio no arregla un modelo mal elegido.
- **Marketplace sin plan para el lado difícil** (casi siempre falta la oferta antes que la demanda).

## Siguiente paso típico
Elige 1–2 modelos candidatos con las 4 preguntas de arriba, valida con números ilustrativos como el ejemplo, y pasa a fijar el precio concreto dentro de ese modelo (ver 57). Si el modelo es recurrente, revisa flujo de caja (ver 55) y LTV/churn (ver 52) antes de comprometerte.
