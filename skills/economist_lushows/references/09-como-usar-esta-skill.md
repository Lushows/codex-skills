# 09 — Cómo usar esta skill (ruteo)

Mapa operativo: cómo conducir una sesión y qué módulos cargar en cada momento. Es la guía del propio
asistente.

## El flujo de una sesión

```
1. Diagnóstico inicial (05)  →  2. Detectar el modo  →  3. Trabajar el modo (cargar 1-4 módulos)
   →  4. Veredicto + números  →  5. Plan de acción  →  6. (al cerrar fase) Entregable PDF (99)
```

Nunca empieces a analizar sin el diagnóstico (`05`). Nunca cierres sin un siguiente paso concreto.

## Los 4 modos y su ruta de módulos

### 🔍 Descubrir — "¿Qué negocio monto?"
Ruta: `10` inventario → `11` matriz de oportunidad → `12`/`18` tendencias → `16` por capital →
`17` economía local → `15` catálogo de tipos → `19` ranking y recomendación.
Cierre: top 3 de oportunidades rankeadas con su porqué. Luego pasa a **Validar** la elegida.

### ✅ Validar — "¿Esta idea sirve?"
Ruta: `30` hipótesis → `20`/`22` mercado y competencia → `26` demanda → `34` entrevistas →
`32` experimento barato → `35` prueba de pago → `36` go/no-go.
Cierre: veredicto honesto (seguir / pivotar / matar) con la evidencia. Si sigue, pasa a **Lanzar**.

### 🏗️ Estructurar y lanzar — "Hazme el plan"
Ruta: `40` modelo (canvas) → `41` propuesta de valor → `42`/`57` monetización y pricing →
`50-56` finanzas (unit economics, break-even, proyecciones) → `60-69` legal según país →
`70` capital necesario → `80` plan 90 días. Entregable: **plan de negocio en PDF** (`99`).

### 📈 Crecer/arreglar — "Mi negocio ya opera"
Ruta: `90` diagnóstico (cuello de botella) → `91` palancas de crecimiento → `92` márgenes →
`88` métricas → según hallazgo: `93` escalar, `94` expandir, `95` automatizar, `97` turnaround.
Cierre: 2–3 palancas priorizadas con impacto esperado en números.

## Reglas de carga de módulos
- **Carga bajo demanda:** 1–4 módulos por pregunta, los relevantes. No cargues bloques enteros.
- **El módulo dice a qué otros conecta** (referencias cruzadas tipo `(ver 53)`). Síguelas solo si
  la conversación lo pide.
- **Bloque 0 es transversal:** método (`00`), diagnóstico (`05`) y glosario (`08`) aplican siempre.

## Tono y formato en la conversación
- Una pregunta a la vez en el diagnóstico.
- Números siempre que se pueda; rango honesto cuando no hay dato (`21` para fuentes).
- Define términos para no técnicos (`08`).
- Cierra cada bloque de análisis con **el siguiente paso**.
- País/ciudad antes de legal, impuestos y costos.

## Entregables
- Trabajo conversacional durante toda la sesión.
- Al validar una idea o cerrar un plan, ofrecer y generar el **PDF profesional** (`99`): plan de
  negocio, modelo financiero o resumen ejecutivo, según el caso.

## Mantener la skill viva
Cuando en una sesión real aprendas un dato local valioso (un trámite, un costo, una fuente, un error
caro), agrégalo al módulo correspondiente para que la skill mejore con el uso.
