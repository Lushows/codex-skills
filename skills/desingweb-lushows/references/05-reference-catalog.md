# Catálogo de referencias de diseño web

Catálogo curado de sitios y marcas de referencia para robar patrones concretos de diseño y motion. Cada entrada dice exactamente **qué robar**: el detalle accionable, no la admiración genérica.

## Herramientas modernas (stack del oficio)

El stack real que usan los estudios de arriba. Agrupado por función para elegir la herramienta correcta según el problema.

**Motion / scroll**
- **GSAP** (gsap.com) — para qué sirve: motor de animación JS basado en timelines, el estándar de la industria para secuencias complejas y ScrollTrigger. Cuándo usarla: cualquier coreografía de scroll o entrada con control fino del tiempo.
- **Lenis** (github.com/darkroomengineering/lenis) — para qué sirve: scroll suave ligero y performante de Darkroom Engineering. Cuándo usarla: base de casi todo sitio premium con parallax o sincronización scroll-WebGL.
- **Motion (Motion.dev)** (motion.dev) — para qué sirve: librería de animación para web y React (antes Framer Motion), gestos e interacciones de alto rendimiento. Cuándo usarla: animaciones declarativas en React; más rápida que GSAP animando entre tipos de valor.
- **Theatre.js** (theatrejs.com) — para qué sirve: animación con editor visual y un solo raf loop para sincronizar con GSAP/Lenis. Cuándo usarla: secuencias cinemáticas y colaboración diseñador-dev sobre keyframes.

**3D / WebGL**
- **Three.js** (threejs.org) — para qué sirve: framework WebGL con control máximo (curva de aprendizaje alta). Cuándo usarla: escenas 3D a medida, shaders y experiencias inmersivas desde cero.
- **OGL** (oframe.github.io/ogl) — para qué sirve: librería WebGL mínima en ES6, cero dependencias, API similar a Three.js. Cuándo usarla: efectos WebGL puntuales (distorsiones, planos de imagen) sin el peso de Three.js.
- **Spline** (spline.design) — para qué sirve: diseño 3D en el navegador con colaboración en tiempo real y embed directo. Cuándo usarla: escenas 3D interactivas en el hero sin escribir shaders.
- **Rive** (rive.app) — para qué sirve: animaciones interactivas con state machine, ligeras y reactivas a eventos. Cuándo usarla: micro-animaciones de UI, mascotas e ilustraciones que responden al usuario.
- **Unicorn Studio** (unicorn.studio) — para qué sirve: herramienta no-code para crear efectos WebGL y volver assets 3D web-ready con optimización automática. Cuándo usarla: efectos WebGL premium sin tocar código ni optimizar .glb a mano.

**Aprendizaje / snippets**
- **Codrops** (tympanus.net/codrops) — para qué sirve: tutoriales y demos de vanguardia en motion, WebGL y scroll desde 2009. Cuándo usarla: aprender una técnica concreta o robar un breakdown con código incluido.
- **Osmo** (osmo.supply) — para qué sirve: dev toolkit con elementos, técnicas y código detrás de trabajo premiado. Cuándo usarla: acelerar producción con snippets probados de motion y layout de élite.

**Diseño**
- **Framer** (framer.com) — para qué sirve: diseño + publicación de sitios con motion declarativo y componentes interactivos. Cuándo usarla: prototipar o lanzar landings animadas rápido sin pipeline de build.
