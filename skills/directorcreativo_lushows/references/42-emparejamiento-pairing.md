# 42 — Emparejamiento (pairing) de tipografías

Combinar fuentes es como vestir: no se trata de juntar las más bonitas, sino de que conversen sin gritarse. La regla maestra: **contraste, no conflicto.**

## El principio: contraste claro
Dos fuentes deben ser o muy parecidas (de la misma familia) o claramente distintas. El error mortal es el "casi igual": dos sans neogrotescas diferentes (Helvetica + Arial) se ven como un accidente, no como una decisión. Si vas a combinar, que el contraste sea evidente y con intención.

Ejes de contraste que funcionan:
- **Estructura**: serif + sans (el clásico que nunca falla).
- **Peso**: titular Black + cuerpo Regular.
- **Escala**: titular enorme + cuerpo pequeño (ver 43, 48).
- **Estilo**: una display expresiva + una neutra de soporte.

## Las 3 estrategias de pairing

### Estrategia A — Una sola superfamilia (la más segura)
Familias diseñadas con versión serif Y sans pensadas para convivir. Cero riesgo de choque, máxima coherencia. Ideal si el cliente es no técnico o el proyecto es grande.
- **IBM Plex** (Sans + Serif + Mono) — gratis, profesional, tech-humana.
- **Source** (Sans + Serif) de Adobe — gratis, neutra y sólida.
- **GT** ecosistema, **Lyon + Atlas** (Commercial Type) — premium.
- **Fraunces + ...** o **Recoleta** para algo más cálido.

### Estrategia B — Serif + Sans (el matrimonio clásico)
Una para titulares con carácter, otra para texto/UI. Funciona porque la estructura contrasta pero los ánimos combinan.

Duplas que funcionan de verdad:

| Titular | Cuerpo / UI | Tono |
|---|---|---|
| **GT Sectra** (serif alto contraste) | **Söhne / Inter** (sans neutra) | Editorial moderno, premium |
| **Tiempos / Tiempos Headline** | **Söhne** | Periodismo de marca, serio elegante |
| **Fraunces** (serif "old wonky") | **Inter** | Cálido, artesanal-moderno, gratis |
| **Playfair Display** | **Source Sans** | Lujo accesible (cuidado: ya muy usada) |
| **Canela / Reckless** | **Founders Grotesk** | Moda, lifestyle de gama alta |
| **Newsreader** | **Public Sans** | Confiable, institucional, gratis |
| **Archer** (slab) | **Gotham** | Amigable y firme (estilo americano) |

### Estrategia C — Una sola familia con muchos pesos (minimalismo de diseñador)
NO combinas: usas una sola sans con buen rango (Light a Black) y construyes TODA la jerarquía con peso, tamaño y color. Resultado limpísimo y muy "estudio de diseño".
- **Inter** sola, **Söhne** sola, **GT America** sola, **Helvetica Now** sola.
- Es la opción de menor riesgo estético. Si dudas, haz esto.

## Reglas prácticas
- [ ] Máximo **2 familias** (3 solo si una es para datos/código mono). Más = caos.
- [ ] Asigna ROLES claros: una para titular, otra para cuerpo. No las mezcles en el mismo nivel.
- [ ] Empareja por **altura-x similar** para que el ritmo del texto no se rompa.
- [ ] Si ambas son sans, que UNA tenga carácter distinto (geométrica + grotesca), nunca dos neogrotescas.
- [ ] Itálicas: úsalas de la MISMA familia, no importes una cursiva ajena.
- [ ] Verifica que ambas tengan acentos y pesos (ver 41).

## Anti-patrones
- Helvetica + Arial (idénticas, parece error).
- Dos scripts juntas (ilegible, recargado).
- Dos display expresivas (se pelean por atención).
- 4+ fuentes "para variedad" (la marca pierde voz).
- Serif clásica formal + script festiva sin razón (mensaje contradictorio).

## Cómo probar un par antes de casarte
1. Maqueta una pieza real: titular grande + subtítulo + 1 párrafo + 1 dato/caption.
2. Mírala impresa o en pantalla a tamaño real, no en zoom.
3. Pregúntate: ¿se siente UNA voz o dos personas hablando encima?
4. Test de español en ambas: *"¿Niño? ¡Acción, sazón!"*.
