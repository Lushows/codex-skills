# 110 — Brand strategy avanzada

La estrategia de marca avanzada es el puente entre "lo que creo de mi negocio" y "el sistema visual que construyo". Este módulo te da las herramientas que usan los estudios grandes (Wolff Olins, Interbrand, Pentagram) para destilar una marca en UNA idea organizadora de la que cuelgue todo: logo, color, tono, fotografía. Si ya leíste 11 (plataforma) y 12 (posicionamiento), esto los une y los activa.

## Por qué "avanzada" no es "más complicada"

La marca avanzada no agrega capas, las QUITA. Una buena estrategia se puede decir en una frase y aun así dirigir cien decisiones. El error del principiante es acumular adjetivos ("moderna, cercana, premium, innovadora, confiable"); el del profesional es encontrar la única tensión que hace única a la marca.

Define dos términos que vas a usar todo el módulo:
- **Brand DNA (ADN de marca):** los 3-4 rasgos no negociables que, si los quitas, deja de ser esa marca.
- **Idea organizadora (organizing idea):** la frase corta que ordena qué SÍ y qué NO hace la marca, hacia adentro y hacia afuera.

## Brand DNA: aislar lo no negociable

El ADN responde: "¿qué tiene esta marca que no se puede copiar con dinero?". No es el logo (se rediseña). No es el producto (se imita). Es la combinación de creencia + comportamiento + voz.

Método del **destilado** (de lo abstracto a lo concreto, ver 11):

| Capa | Pregunta | Ejemplo (Patagonia) |
|---|---|---|
| Creencia | ¿En qué cree? | El planeta importa más que el crecimiento |
| Tensión | ¿Qué contradicción asume? | Vender ropa Y pedir que compres menos |
| Comportamiento | ¿Qué hace que otros no? | "Don't buy this jacket", repara gratis |
| Voz | ¿Cómo suena? | Activista, técnica, sin glamour falso |

Si las cuatro filas son intercambiables con tu competencia, no tienes ADN: tienes una categoría.

## La idea organizadora: el corazón del sistema

Es la frase de la que cuelga TODO. No es un eslogan publicitario (ese es externo y cambia). Es interna y dura años. Referentes reales verídicos:

- **Airbnb → "Belong Anywhere" (pertenecer en cualquier lugar).** De ahí salió el símbolo "Bélo" (un corazón + ubicación + persona), una paleta cálida y fotografía de gente real en casas reales, no hoteles.
- **Nike → "Authentic athletic performance".** Justifica el swoosh de movimiento, el negro/naranja deportivo y campañas centradas en el atleta, no en el producto.
- **Mailchimp (rediseño 2018, Collins) → "humor + craft para empresas pequeñas".** De ahí el amarillo Cavendish chillón, ilustración rara hecha a mano y el chimp Freddie con personalidad.

La prueba: si tu idea organizadora no descarta una opción de color, una tipografía o un tipo de foto, es demasiado blanda.

## Brand Onion (la cebolla de marca)

Herramienta clásica para ordenar de adentro (estable) hacia afuera (visible). Llénala de centro a borde:

```
        ┌─────────────────────────────┐
        │   EXPRESIÓN (logo, color,   │  ← lo que se ve / cambia más
        │   tipo, tono, foto)         │
        │   ┌───────────────────────┐ │
        │   │  PERSONALIDAD          │ │  ← cómo se comporta (ver 14)
        │   │  ┌─────────────────┐   │ │
        │   │  │  BENEFICIOS      │   │ │  ← qué gano (racional+emocional)
        │   │  │  ┌───────────┐   │   │ │
        │   │  │  │  ESENCIA   │   │   │ │  ← el alma, 2-3 palabras (ver 11)
        │   │  │  └───────────┘   │   │ │
        │   │  └─────────────────┘   │ │
        │   └───────────────────────┘ │
        └─────────────────────────────┘
```

Regla de oro: **el centro casi no cambia; el borde es donde innovas.** Un rebrand sano cambia el borde sin traicionar el centro (ver 111).

## De estrategia a sistema visual (el puente)

Aquí es donde la mayoría falla: tienen un PDF de estrategia bonito que nadie traduce a diseño. Usa esta **tabla puente** para forzar cada palabra estratégica a una decisión visual:

| Rasgo de ADN | Implicación visual concreta | Lo que DESCARTA |
|---|---|---|
| "Rigor científico" | Tipo grotesca limpia, datos visibles, grid estricto | Scripts, texturas sucias |
| "Calidez humana" | Fotografía de gente real, paleta cálida, esquinas suaves | Render frío, azul corporativo |
| "Rebeldía" | Contraste alto, escala brutal, regla rota a propósito | Centrado, simétrico, "seguro" |
| "Artesanal" | Trazo a mano, papel, imperfección controlada | Vectores perfectos, degradados de stock |

Si una decisión visual no se puede defender desde una fila de esta tabla, es gusto personal, no estrategia.

## Proceso de trabajo (sesión real)

1. [ ] Entrevista al dueño: "¿qué perderíamos si esto desapareciera mañana?" (busca el ADN).
2. [ ] Lista 10 frases candidatas a idea organizadora; tacha las que tu competidor podría firmar (ver 11).
3. [ ] Llena la Brand Onion de centro a borde.
4. [ ] Construye la tabla puente: cada rasgo → una implicación visual + un descarte.
5. [ ] Escribe la idea organizadora en UNA frase y pégala arriba del moodboard (ver 66).
6. [ ] Valida: ¿esta frase me deja decir NO a algo? Si no, vuelve al paso 2.

## Ejemplo trabajado: BIO-SETA

- **ADN:** Naturaleza real + rigor científico + honestidad ("no prometemos magia").
- **Idea organizadora:** "Hongos que se explican solos." (Todo debe sentirse comprensible, no esotérico.)
- **Tabla puente:** "rigor" → tipografía grotesca + dato de mg visible en empaque → descarta lo místico/chamánico; "naturaleza" → paleta tierra/verde apagado → descarta neón; "honestidad" → foto del hongo real, no ilustración fantástica → descarta el render dramático.
- Resultado: la estrategia ya está eligiendo el diseño antes de abrir el editor.

## Errores típicos

- Estrategia de cinco adjetivos genéricos (no diferencia nada).
- Idea organizadora que es un eslogan de campaña (caduca en un año).
- PDF de estrategia que nunca se traduce a decisiones visuales (la tabla puente lo evita).
- Cambiar el centro de la cebolla en cada rediseño (eso destruye equity, ver 111 y 119).

## Siguiente paso
