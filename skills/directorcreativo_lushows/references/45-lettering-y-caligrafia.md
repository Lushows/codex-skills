# 45 — Lettering y caligrafía

A veces ninguna fuente del mundo dice exactamente lo que la marca necesita. Ahí entra dibujar las letras a mano. Pero "letras a mano" abarca tres oficios distintos que la gente confunde. Aclararlos es el primer paso.

## Las tres disciplinas (no son lo mismo)

| Disciplina | Qué es | Naturaleza |
|---|---|---|
| **Tipografía** | Diseñar un SISTEMA de letras reutilizables (una fuente) | Un sistema |
| **Lettering** | DIBUJAR letras para una pieza específica, una sola vez | Un dibujo |
| **Caligrafía** | ESCRIBIR letras a mano con herramienta (pluma, pincel) en un gesto fluido | Una escritura |

En simple:
- **Caligrafía** = se escribe (gesto continuo, herramienta cargada de tinta).
- **Lettering** = se dibuja y se corrige (construyes cada letra, la borras, la refinas; no hay "gesto único").
- **Tipografía** = se diseña una vez para usarse mil veces.

## Caligrafía
La letra como gesto. La belleza viene del trazo, la presión, el ritmo de la mano. Cada copia es ligeramente distinta (es escritura, no diseño).
- **Herramientas**: pluma de punta ancha (góticas, itálicas), pluma flexible (caligrafía inglesa, copperplate), pincel (brush lettering, oriental).
- **Usos de marca**: firmas, packaging artesanal, vino, repostería, bodas, lujo personal.
- **Cuándo SÍ**: cuando quieres calidez humana, tradición, lo hecho a mano, autenticidad.
- **Diseñadores/referentes**: la tradición copperplate; estudios contemporáneos de hand-lettering.

## Lettering
La letra como dibujo construido. Aquí controlas cada curva, cada empalme, cada espacio. Es lo que hay detrás de la mayoría de logotipos memorables.
- **Proceso**: boceto a lápiz → refinado → vectorizado (Illustrator) → ajuste fino.
- **Ventaja sobre la fuente**: cada letra se diseña para ESAS palabras concretas, con empalmes y proporciones imposibles en una fuente genérica.
- **Usos**: logotipos, portadas, murales, etiquetas, titulares de campaña.

## Cuándo dibujar letras únicas (vs. usar una fuente)
Dibuja lettering custom cuando:
- [ ] El logotipo necesita un carácter que NINGUNA fuente da.
- [ ] Quieres que sea imposible de replicar tipeando el nombre en una fuente comprable.
- [ ] El nombre tiene letras con potencial de juego (ligaduras, empalmes, un ascendente que se vuelve símbolo).
- [ ] La marca vende artesanía/autenticidad y el trazo a mano ES el mensaje.
- [ ] Es una pieza única de alto impacto (portada, mural, campaña).

Usa una fuente (ajustada, ver 46) cuando:
- [ ] Presupuesto/tiempo limitado.
- [ ] Necesitas un sistema que escale a muchas piezas y personas.
- [ ] El nombre funciona bien con una buena fuente + kerning afinado.

## El error clásico: confundir "tipear una script" con lettering
Poner el nombre en una fuente script (Lobster, Pacifico, Brush Script) NO es lettering: es usar una fuente que millones ya usan, con empalmes genéricos y repeticiones idénticas de cada letra. Se ve barato y reconocible como plantilla. El lettering real dibuja cada letra para esas palabras.

## De la mano al vector (flujo profesional)
1. **Concepto + referencias**: ¿qué estilo? (script elegante, sans condensada custom, retro, etc.)
2. **Bocetos a lápiz**: muchas variantes rápidas, busca el ritmo.
3. **Refinado**: limpia el mejor boceto, corrige proporciones y espacios.
4. **Vectorización**: en Illustrator con la pluma (Bézier), no autotrace.
5. **Ajuste fino**: equilibra contraformas, empalmes y grosores ópticamente (el ojo manda, no la regla).
6. **Pruebas**: a tamaño grande y pequeño, en positivo y negativo.

## Riesgos a vigilar
- Legibilidad: el lettering elaborado puede volverse ilegible en chico. Prueba a 16 px.
- Consistencia: las letras dibujadas deben sentirse de la misma "familia" (mismo ángulo, mismo grosor relativo).
- Acentos en español: la ñ y las tildes también se dibujan, no se olvidan.
- Escalabilidad: si la marca necesitará subtítulos y textos, igual hará falta una fuente de soporte (ver 42, 44).
