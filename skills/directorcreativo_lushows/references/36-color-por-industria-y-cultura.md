# 36 — Color por industria y cultura

Cada sector tiene un "código cromático" no escrito: colores que la gente espera y que comunican pertenencia a esa categoría. Conocerlos te deja dos jugadas: SEGUIR el código para dar confianza, o ROMPERLO con criterio para destacar. Ambas son válidas; lo que no vale es ignorarlo sin saberlo.

## Por qué existen los códigos de sector
La gente lee marcas por patrones. Si todos los bancos son azules y llegas con uno azul, "lees como banco" → confianza instantánea. Pero si TODOS son azules, también te vuelves invisible. La decisión de seguir o romper depende de tu estrategia, no del azar.

## Códigos cromáticos por industria

### Finanzas / banca / seguros → AZUL
Confianza, solidez, seguridad. Visa, PayPal, Chase, BBVA. El azul domina porque la categoría vende "tu dinero está seguro". Romperlo: marcas fintech jóvenes usan colores vivos (Revolut, N26 con negro/tech, Nubank con **púrpura** `#820AD1` —rompió el código y se volvió ícono).

### Salud / farma / bienestar → AZUL + VERDE + BLANCO
Limpieza, confianza, cuidado. Azul clínico, verde de salud natural, mucho blanco. Para suplementos naturales/orgánicos: **verdes terrosos y tierras** comunican lo natural mejor que el azul clínico.

### Eco / orgánico / sostenible → VERDE (+ tierras, kraft)
Naturaleza, pureza, sostenibilidad. Verdes orgánicos, marrones tierra, papel kraft sin blanquear. Whole Foods, marcas bio. Cuidado con el "greenwashing visual": verde solo no basta, debe sentirse honesto. (Ideal para hongos funcionales y productos de laboratorio natural.)

### Lujo / premium → NEGRO, BLANCO, DORADO
Exclusividad, atemporalidad, sofisticación. Chanel, Prada, Rolex. La regla del lujo es RESTAR: poca saturación, mucho espacio, negro/blanco con un metálico. Color saturado = casi siempre menos lujoso. El dorado da herencia; el plata, modernidad.

### Comida / restaurantes → CÁLIDOS (rojo, naranja, amarillo)
Apetito, energía, urgencia. Rojo y amarillo estimulan el hambre y la rapidez (McDonald's, KFC, Burger King). Comida sana/premium rompe con verdes y tierras. Comida artesanal: marrones y crema.

### Tech / software → AZUL, NEGRO, GRADIENTES vivos
Innovación, confianza, futuro. Azul (IBM, Intel) o negro minimalista (Apple). Las tech jóvenes usan gradientes y acentos saturados (ver 37) para diferenciarse. Cuidado con el cliché del degradado morado-azul "IA" (ver 37).

### Infantil / juguetes / dulces → PRIMARIOS BRILLANTES, TRÍADAS
Diversión, energía, juego. Colores saturados, muchos colores, tríadas (ver 30). LEGO, Toys, M&M's.

### Belleza / cosmética → ROSA, NUDE, NEGRO, DORADO
Según el posicionamiento: rosa/nude = suave y femenino (Glossier); negro/dorado = lujo (MAC, Dior); colores vivos = juvenil disruptor.

### Deporte / fitness → NEGRO + ACENTO NEÓN, ROJO
Energía, potencia, movimiento. Negro con un acento de alta energía (volt/neón verde de Nike, naranja, rojo). Contraste fuerte = adrenalina.

### Legal / corporativo / B2B serio → AZUL MARINO, GRIS, BURDEOS
Autoridad, tradición, seriedad. Tonos oscuros y sobrios, poco saturados.

## Matices culturales y regionales (ver también 31)
El significado del color cambia por región. Si tu marca es local o exporta, verifica:
- **China**: rojo = suerte/prosperidad (bodas, Año Nuevo); blanco = luto. El rojo vende.
- **India**: colores saturados y vibrantes son celebración (azafrán, magenta, dorado). El blanco solo puede leerse fúnebre.
- **Mundo islámico / Medio Oriente**: verde = sagrado y positivo; úsalo con respeto.
- **Latinoamérica**: cálidos y saturados conectan con calidez/fiesta; el púrpura puede asociarse a luto (Cuaresma) en contextos católicos.
- **Norte de Europa**: paletas más sobrias y desaturadas se leen como "calidad/diseño".
- **EE.UU.**: verde = dinero; rojo/blanco/azul = patriotismo.

Regla: NO asumas que tu lectura del color es universal. Pregunta a personas del mercado real.

## Cuándo SEGUIR el código y cuándo ROMPERLO
**Sigue el código si:**
- Eres nuevo y necesitas confianza inmediata (banca, salud, legal).
- La categoría tiene expectativas fuertes de seguridad/seriedad.

**Rómpelo con criterio si:**
- El sector está saturado del mismo color y necesitas destacar (Nubank púrpura en banca azul; T-Mobile magenta en telco azul).
- Tu posicionamiento ES la diferencia (disruptor, joven, premium distinto).
- Tienes presupuesto/tiempo para EDUCAR el nuevo código (romper cuesta más).

**Cómo romper sin perder la categoría:** mantén UNA señal del código (ej: un toque de azul de confianza) y rompe en el resto. O conserva los códigos de FORMA/tipografía y rompe solo en color. Romper TODO a la vez confunde.

## Proceso
1. Identifica el código cromático de tu sector (lista arriba).
2. Mira qué hacen los 3–5 competidores principales: ¿todos iguales?
3. Decide estrategia: confianza (seguir) o diferenciación (romper).
4. Verifica los matices culturales de tu mercado real.
5. Si rompes, deja una ancla que aún diga "soy de esta categoría".
