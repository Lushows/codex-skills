# 19 — Auditoría de marca

Antes de rediseñar una marca existente, hay que diagnosticarla. Tocar sin diagnóstico es como operar sin radiografía. Este módulo te da el inventario de activos, los ejes de evaluación (consistencia, percepción, brecha) y una plantilla de reporte para el modo Rediseño.

## Cuándo usar este módulo

Úsalo cuando la marca YA existe y quieres mejorarla, no cuando creas desde cero. La tentación del no técnico es "rehagamos el logo ya". Error: primero entiendes qué tienes, qué funciona (no se toca) y qué falla (se arregla). Un rediseño que borra lo bueno destruye reconocimiento ganado (caso clásico: el rebrand de Tropicana en 2009 que ignoró sus activos icónicos y hundió ventas ~20% en semanas; tuvieron que revertirlo).

## Los 4 ejes de la auditoría

```
1. INVENTARIO   → ¿Qué activos de marca tengo hoy?
2. CONSISTENCIA → ¿Se usan igual en todos lados?
3. PERCEPCIÓN   → ¿Qué piensa/siente el cliente realmente?
4. BRECHA       → ¿Cuánto se aleja lo que SOY de lo que QUIERO ser?
```

### Eje 1 — Inventario de activos

Lista TODO lo visible de la marca y dónde aparece. No se puede arreglar lo que no se ha mapeado.

| Activo | ¿Existe? | ¿Dónde aparece? | Estado |
|---|---|---|---|
| Logo (versiones) | | empaque, web, redes, factura | |
| Paleta de color | | | |
| Tipografías | | | |
| Fotografía / estilo | | | |
| Empaque / etiquetas | | | |
| Web / landing | | | |
| Redes (feed, avatar) | | | |
| Tono de voz / copy | | mensajes, bot, anuncios | |
| Eslogan / claim | | | |

Marca como **activos icónicos** los elementos que el cliente ya reconoce y asocia contigo (un color, un símbolo, una frase). Esos NO se botan sin razón gravísima: son tu reconocimiento acumulado.

### Eje 2 — Consistencia

Mide si la marca se ve y suena igual en todos los puntos de contacto. La inconsistencia destruye reconocimiento (módulo 10).

Revisa y anota desviaciones:
- [ ] ¿El logo se usa igual (mismas versiones, sin deformar)?
- [ ] ¿Los colores son los mismos códigos en web, empaque y redes?
- [ ] ¿La tipografía es consistente o cada pieza usa otra?
- [ ] ¿El tono de voz es el mismo en web, redes y WhatsApp/bot?
- [ ] ¿La calidad de las fotos es pareja?

Puntúa cada uno 1-5. Un promedio bajo = el problema no es el logo, es la disciplina de uso (a veces no necesitas rediseñar, sino un manual y aplicarlo).

### Eje 3 — Percepción

Qué piensa el cliente vs qué quieres que piense. Recuerda: la marca vive en su mente (módulo 10), no en tu intención.

Cómo medir sin presupuesto:
- Pregunta a 5-10 clientes: "Describe mi marca en 3 palabras." Anota las palabras que se repiten.
- Mina tus conversaciones reales (chats, reseñas, comentarios): ¿qué asocian? ¿qué dudas/objeciones repiten?
- Compara con la competencia: ¿en qué te ven distinto o igual?

Luego contrasta:
```
QUIERO que piensen: confiable, natural, con rigor
PIENSAN de verdad:  natural sí, pero "no sé si funciona", "se ve informal"
→ BRECHA: falta señal de rigor/confianza. El rediseño debe atacar eso.
```

### Eje 4 — Brecha (gap)

La distancia entre la marca actual y la marca deseada (tu plataforma/big idea de los módulos 11 y 17). El rediseño existe para cerrar ESA brecha específica, no para "verse más bonito".

```
ACTUAL ────────[ brecha ]──────── DESEADA
(lo que percibe el cliente hoy)   (plataforma + big idea)
```

Define la brecha en frases concretas: "Hoy nos perciben informales; queremos que nos perciban rigurosos pero cercanos." Cada decisión del rediseño debe cerrar esa frase.

## Plantilla de reporte de auditoría

```
AUDITORÍA DE MARCA — [nombre] — [fecha]

1. RESUMEN EJECUTIVO (3 líneas)
   Estado general: ___. Principal fortaleza: ___. Principal problema: ___.

2. INVENTARIO DE ACTIVOS
   [tabla] — Activos icónicos a CONSERVAR: ___

3. CONSISTENCIA (promedio /5: __)
   Mayores desviaciones: ___

4. PERCEPCIÓN
   Lo que quiero que piensen: ___
   Lo que piensan de verdad: ___

5. BRECHA
   Frase de brecha: "Hoy nos perciben ___; queremos ___."

6. DIAGNÓSTICO
   [ ] No necesita rediseño, solo disciplina de uso + manual
   [ ] Necesita refresh (ajustes, conservando activos icónicos)
   [ ] Necesita rediseño profundo (la marca actual contradice lo deseado)

7. RECOMENDACIÓN
   Qué conservar: ___  | Qué ajustar: ___  | Qué rehacer: ___
```

## Ejemplo trabajado: auditoría de BIO-SETA (modo Rediseño)

```
RESUMEN: marca con buen producto pero imagen dispersa. Fortaleza: confianza
de clientes que ya compran. Problema: se ve informal, inconsistente entre redes
y empaque; no transmite rigor.

INVENTARIO: logo improvisado, colores que varían (verde distinto en cada pieza),
fotos de calidad desigual, tono del bot a veces sobrio a veces con muchos emojis.
ACTIVOS ICÓNICOS A CONSERVAR: el nombre BIO-SETA (ya reconocido) y el verde
como color base (asociación natural ya instalada).

CONSISTENCIA: 2/5. El verde cambia de tono; tipografía distinta en cada lugar.

PERCEPCIÓN:
  Quiero: confiable, natural, con evidencia.
  De verdad: "natural sí, pero ¿funciona?, se ve casero/informal".

BRECHA: "Hoy nos perciben informales y dudan que funcione;
queremos que nos perciban rigurosos, honestos y cercanos."

DIAGNÓSTICO: [x] Refresh con manual (no borrar nombre ni verde;
unificar tono de verde, tipografía con autoridad, fotos limpias con datos,
tono del bot consistente).

RECOMENDACIÓN:
  Conservar: nombre, idea de "verde natural".
  Ajustar: unificar paleta, sistema tipográfico, estilo de foto, voz del bot.
  Rehacer: logo (a algo con más autoridad), empaque, estructura de redes.
```

Nota cómo la auditoría evitó el error de "botar todo": se conserva lo reconocido (nombre, verde) y se ataca la brecha real (falta de rigor percibido).

## Errores frecuentes

- **Rediseñar sin auditar:** botas activos valiosos sin saberlo (efecto Tropicana).
- **Confundir "no me gusta" con "no funciona":** tu gusto no es el diagnóstico; la percepción del cliente sí.
- **Cambiar todo por moda:** si no cierra una brecha real, es gasto, no inversión.
- **Ignorar la consistencia:** a veces no hace falta rediseñar, solo USAR bien lo que ya hay.

## Checklist

- [ ] Inventarié todos los activos y marqué los icónicos.
- [ ] Puntué la consistencia y anoté desviaciones.
- [ ] Medí percepción real con clientes/chats, no suposiciones.
- [ ] Definí la frase de brecha (actual → deseada).
- [ ] Decidí: disciplina, refresh o rediseño profundo.
- [ ] Listé qué conservar / ajustar / rehacer.
