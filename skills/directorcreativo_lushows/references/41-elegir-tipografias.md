# 41 — Elegir tipografías con propósito

Una fuente no es decoración: es la VOZ de la marca antes de leer una palabra. Elegir bien es elegir un tono de voz. Este módulo te da los criterios reales y te aleja de la fuente cliché.

## La pregunta que va primero
No es "¿qué fuente está de moda?" sino **"¿qué quiere decir esta marca SIN palabras?"**. Una fuente geométrica (Futura) dice "moderno, racional, de diseño". Una old style (Garamond) dice "tengo historia, confía en mí". Una slab (Archer) dice "soy firme pero cercano". Define el adjetivo primero, la fuente después.

## Los 6 criterios de selección

### 1. Personalidad (el adjetivo)
Escribe 3 adjetivos de la marca (ej: "cálida, natural, confiable" para BIO-SETA). Cada fuente proyecta carácter:
- Lujo frío / moda → didona (Didot) o serif de alto contraste (GT Sectra)
- Tecnología amable → geométrica (Circular, Gotham, Avenir)
- Salud / naturaleza / confianza → humanista (Frutiger, Source Sans) o old style cálida (Sabon)
- Editorial / autoridad → transicional (Baskerville, Tiempos)
- Artesanal / personal → lettering o script con criterio

### 2. Legibilidad vs. expresividad
Regla de oro: **el cuerpo de texto se elige por legibilidad; el titular se elige por carácter.** Nunca pongas una display en un párrafo. Para cuerpo: altura-x media-alta, contraformas abiertas, pesos bien diferenciados.

### 3. Rango de pesos (lo más subestimado)
Una buena familia de trabajo trae al menos Light, Regular, Medium, Semibold, Bold + itálicas. Con UNA familia bien dotada construyes toda la jerarquía sin combinar nada (ver 42). Si una fuente solo tiene Regular y Bold, te quedarás corto. Revisa esto SIEMPRE antes de enamorarte.

### 4. Idioma y acentos (crítico en español)
Necesitamos **á é í ó ú ñ ¿ ¡ ü**. Muchas fuentes display gratuitas NO traen ñ ni signos de apertura. Test obligatorio: escribe *"¿Niño? ¡Acción, sazón, pingüino!"* y verifica que todo se vea bien y consistente. Una ñ mal hecha arruina una marca latinoamericana.

### 5. Licencia (ver 49)
¿La puedes usar en web? ¿en una app? ¿comercialmente? Una fuente bonita con licencia equivocada es un problema legal esperando. Verifica desktop / web / app antes de comprometerte.

### 6. Contexto de uso real
¿Dónde vivirá? Pantalla pequeña (necesita altura-x alta, hinting bueno: Inter, Source Sans), impresión fina (puede aguantar más contraste: Garamond), señalética (humanista clara: Frutiger). Elige para el medio dominante (ver 47).

## Errores comunes (la lista negra)
- [ ] **Default por costumbre**: Montserrat / Poppins / Lato / Open Sans porque "se ven bien". Se ven a IA genérica. Úsalas solo si hay una razón real, no por inercia.
- [ ] **Elegir por el titular, olvidar el cuerpo**: la display preciosa que no tiene versión legible.
- [ ] **Fuente sin pesos suficientes**: jerarquía pobre.
- [ ] **Ignorar acentos en español**.
- [ ] **5 fuentes "para tener variedad"**: caos. Máximo 2–3 (ver 42).
- [ ] **Comic Sans, Papyrus, Bleeding Cowboys, Brush Script**: clichés muertos. Cero.
- [ ] **Copiar la fuente del competidor**: te vuelves invisible junto a él.

## Cómo evitar la fuente cliché
1. Pregunta: "¿esta fuente ya la asocio con 100 marcas?" → busca una prima menos usada. En vez de Montserrat (geométrica) → **Aktiv Grotesk, Söhne, GT America, Sequel**. En vez de Lato → **Inter, Source Sans, IBM Plex Sans**.
2. Busca fundidoras serias: **Klim (Söhne, Tiempos), Grilli Type (GT Sectra, GT America), Commercial Type, Dinamo, Pangram Pangram, Hoefler&Co.**
3. Para presupuesto cero con calidad: **Inter, Source Sans/Serif, IBM Plex, Fraunces, Newsreader, Space Grotesk, Libre Franklin, Public Sans** (ver 49).

## Mini-proceso de decisión
1. Escribe 3 adjetivos de marca.
2. Elige familia maestra para cuerpo (legibilidad + pesos + acentos).
3. Elige (opcional) una de carácter para titulares.
4. Test de español: *"¿Niño? ¡Acción!"*.
5. Verifica licencia para tu medio.
6. Pruébalas en una pieza real (titular + párrafo + caption), no en una palabra suelta.
