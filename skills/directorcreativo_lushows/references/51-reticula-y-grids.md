# 51 — Retícula y grids

La retícula (grid) es el **esqueleto invisible** sobre el que se cuelga todo. No se ve en la pieza final, pero es la razón por la que una pieza se siente ordenada y otra se siente amateur. Josef Müller-Brockmann escribió la biblia: *Grid Systems in Graphic Design* (1981).

## Por qué existe
- Da **consistencia**: todas las piezas comparten lógica.
- Acelera decisiones: ya no colocas "a ojo", sino sobre líneas.
- Permite **escalar**: cualquiera puede maquetar una pieza nueva sin romper el sistema (ver 59).
- Crea armonía: relaciones matemáticas que el ojo percibe como "bien hecho".

## Anatomía de una retícula

| Parte | Qué es | Simple |
|---|---|---|
| **Margen** | Aire en los 4 bordes | El marco de respeto alrededor |
| **Columna** | Franjas verticales donde va el contenido | Los "carriles" del texto |
| **Medianil (gutter)** | Espacio ENTRE columnas | El pasillo entre carriles |
| **Módulo** | Celda cuando hay también filas | El "ladrillo" de la cuadrícula |
| **Zona espacial** | Grupos de módulos para un uso | Bloques reservados (foto, titular) |
| **Baseline / línea base** | Líneas horizontales donde se apoya el texto | Renglones invisibles |
| **Marcador de flujo** | Dónde empieza/termina cada elemento | Puntos de anclaje |

## Los 4 tipos de retícula (Müller-Brockmann / Tschichold)

### 1. Grid de manuscrito (1 columna)
Un solo bloque de texto con márgenes. Para libros, ensayos, cartas largas.
- Clave: márgenes generosos. El margen exterior suele ser el mayor.
- Riesgo: aburre si el texto es muy largo y la columna muy ancha.

### 2. Grid de columnas (2–6 columnas)
Varias columnas verticales. El caballo de batalla de revistas, webs, flyers.
- El texto puede ocupar 1 columna o saltar varias.
- Las imágenes se anclan a columnas (1, 2, 3… de ancho).
- Lo más versátil para empezar.

### 3. Grid modular (columnas + filas = módulos)
Cruzas columnas con filas → cuadrícula de celdas. Para catálogos, tablas, dashboards, periódicos, calendarios.
- Cada elemento ocupa N módulos. Da orden ferreo (ver dashboards, ver 59).
- Es la base del sistema suizo.

### 4. Grid jerárquico
Retícula a medida, no uniforme, adaptada a un contenido único (un poster con un titular enorme + bloques irregulares).
- Más libre, pero sigue teniendo alineaciones intencionales.
- Para piezas de impacto donde el contenido manda.

## Conceptos que dan armonía
- **Ancho de columna legible:** una línea de texto cómoda tiene **45–75 caracteres** (≈9–12 palabras). Más ancho cansa, más angosto fragmenta.
- **Baseline grid:** todas las líneas de texto y elementos se apoyan en una grilla horizontal común (ej. cada 4 u 8 px). Da ritmo vertical impecable.
- **Sistema de 8 puntos:** muchos diseñadores espacian todo en múltiplos de 8 (8, 16, 24, 32…). Decisiones rápidas y consistentes. En print suele usarse múltiplos en mm.
- **Regla de los tercios / proporción áurea:** divisiones agradables para ubicar focos. Útiles, no obligatorias.

## Cómo definir una retícula (proceso)
1. **Elige el formato** (A4, cuadrado IG 1080×1080, story 1080×1920, etc.).
2. **Pon los márgenes.** Empieza generoso. Un margen tímido se ve barato.
3. **Decide columnas.** Para empezar: 12 columnas (web/flyer flexible) o 6 (más simple). 12 divide en 2, 3, 4, 6 → muy flexible.
4. **Fija el medianil** (ej. 16 o 24 px) coherente con tu sistema de 8.
5. **Define un baseline** (ej. 8 px) y alinea el texto a él.
6. **Crea zonas espaciales** si hace falta (banda superior para logo, zona inferior para datos).
7. **Maqueta sobre la retícula** y solo rompe la grid a propósito, nunca por descuido.

## Ejemplo concreto: post de Instagram 1080×1080
- Márgenes: 80 px en los 4 lados → zona útil 920×920.
- Columnas: 6 columnas, medianil 24 px.
- Titular: ocupa columnas 1–6 (ancho completo) arriba.
- Producto/foto: columnas 1–4. Dato/precio: columnas 5–6.
- Logo: anclado abajo a la izquierda, sobre la línea base inferior.
- Resultado: aunque cambies el contenido, todo cae en su sitio.

## Cuándo (y cómo) romper la grid
La retícula es una herramienta, no una cárcel. Rómpela para crear tensión o un foco — pero **solo un elemento**, y que se note que es deliberado. Si rompes todo, no rompiste nada: solo es desorden.

## Errores típicos
- Márgenes tacaños → todo apretado, se ve barato.
- No usar grid → elementos flotando, alineaciones imposibles.
- Columna de texto demasiado ancha → ilegible.
- Mezclar muchas grids distintas entre piezas → se pierde el sistema (ver 59).

## Referentes
- **Josef Müller-Brockmann** — *Grid Systems*; el orden suizo.
- **Jan Tschichold** — *The New Typography*; proporciones y márgenes clásicos.
- **Karl Gerstner** — grids programáticos.
