# 49 — Fuentes recomendadas y licencias

Un catálogo curado de fuentes que funcionan de verdad (incluidas gratuitas de élite), dónde conseguirlas y cómo no meterte en un lío legal. Tener buen gusto es saber QUÉ usar y CON QUÉ derecho usarlo.

## Dónde conseguirlas
- **Google Fonts** (fonts.google.com) — gratis, libre uso comercial (licencia OFL, ver abajo).
- **Adobe Fonts** (fonts.adobe.com) — incluidas en Creative Cloud; web y desktop mientras pagues.
- **Sitio de la fundidora** (Klim, GT, etc.) — compra directa, mejores precios y licencias claras.
- **Distribuidores**: MyFonts, Fontspring (Fontspring tiene licencias más justas, sin pago recurrente en muchas), Future Fonts (fuentes en desarrollo, baratas).
- **Pangram Pangram, Velvetyne, Collletttivo** — fuentes de carácter gratis o freemium.

⚠️ NUNCA descargues fuentes "premium gratis" de sitios piratas (dafont a veces, sitios de cracks). Es ilegal, suelen venir incompletas (sin acentos/kerning) y te expones a reclamos.

## Tipos de licencia (lo que DEBES entender)
Una fuente no se "compra"; se licencia para un USO específico. Pagar una no cubre todos los usos.

| Licencia | Qué permite | Cuándo la necesitas |
|---|---|---|
| **Desktop** | Instalarla en computadoras, diseñar piezas, IMPRIMIR | Logos, print, artes en Illustrator/Photoshop |
| **Web** | Servirla en un sitio (self-host con @font-face) | Tu página web. Suele cobrarse por pageviews/mes |
| **App** | Embeberla en una app móvil/escritorio | Apps iOS/Android |
| **ePub / Digital** | Libros digitales, PDFs incrustados | Editoriales |
| **Broadcast / Server** | TV, video, servidores | Casos grandes |

**Punto crítico**: la licencia **desktop NO cubre web ni app.** Comprar la desktop e incrustarla en tu web es una infracción. Para web necesitas la licencia web (o self-host autorizado). Verifica SIEMPRE el alcance.

## Licencias libres (las que dan tranquilidad)
- **OFL (SIL Open Font License)**: la de Google Fonts. Uso comercial libre, en web, app, print, sin pagar ni atribuir. Puedes incluso modificarla. La más cómoda para pymes.
- **Apache 2.0**: similar, libre uso comercial (algunas de Google).
- Estas cubren prácticamente cualquier uso de una pyme sin costo ni riesgo.

## Cómo evitar problemas legales (checklist)
- [ ] ¿La fuente es OFL/Apache (libre) o tengo licencia comprada?
- [ ] ¿Mi licencia cubre el USO real (desktop + web + app si aplica)?
- [ ] Para web: ¿tengo licencia web o uso Google/Adobe Fonts/OFL?
- [ ] ¿La descargué de fuente legítima (no pirata)?
- [ ] ¿Guardé el comprobante/licencia por si la fundidora audita?
- [ ] Para el logo: ¿convertí a curvas? (así el logo no "usa" la fuente, ya es un dibujo — pero el diseño SÍ requirió licencia desktop)
- [ ] ¿La licencia es por volumen (pageviews)? ¿Mi tráfico la excede?

## Recomendación por escenario (atajos)
- **Pyme presupuesto cero, web**: Inter (UI) + Fraunces o Newsreader (titulares). Google Fonts, OFL, listo.
- **Marca que quiere verse premium sin custom**: licenciar Söhne o GT America (Klim/GT) + una serif del mismo ecosistema.
- **Producto/app tech**: IBM Plex (gratis) o system fonts (San Francisco/Segoe/Roboto) para máxima velocidad.
- **Editorial / contenido largo**: Newsreader o Spectral (gratis), o Tiempos (pago) si hay presupuesto.
