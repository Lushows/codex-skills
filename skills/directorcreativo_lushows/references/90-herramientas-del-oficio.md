# 90 — Herramientas del oficio

Las herramientas no hacen al diseñador, pero usar la equivocada cuesta horas y arruina el resultado. Esta es la caja de herramientas real de 2026 y, sobre todo, **cuál para qué tarea**.

## La regla de oro
La herramienta correcta depende de qué estás haciendo, no de cuál sabes usar. Un logo en Photoshop se ve "bien" en pantalla y se rompe en la imprenta (ver 93 sobre vector vs mapa de bits). Elegir mal el programa es la causa #1 de archivos inservibles.

## Las cinco herramientas que importan

| Herramienta | Para qué es REINA | Para qué NO sirve | Quién la usa |
|---|---|---|---|
| **Adobe Illustrator** | Vector: logos, isotipos, íconos, ilustración plana, etiquetas | Editar fotos, maquetar revistas largas | Diseñador de marca |
| **Adobe Photoshop** | Imagen de pixeles: retoque foto, composición, mockups, texturas | Logos, textos largos, vector escalable | Retocador, fotógrafo |
| **Adobe InDesign** | Editorial: manuales, catálogos, brochures, cualquier doc multipágina | Logos, edición de foto | Diseñador editorial |
| **Figma** | UI/web/app, prototipos, colaboración en tiempo real, design systems | Print pesado, ilustración compleja | Diseñador de producto/UI |
| **Canva** | Rápido, plantillas, redes sociales, no-diseñador | Marca seria desde cero, archivos de imprenta | Dueño de negocio, marketing |

## Cuál usar para cada tarea (tabla de decisión)

| Necesito... | Uso |
|---|---|
| Diseñar un logo | **Illustrator** (siempre vector) |
| Diseñar una etiqueta de producto | **Illustrator** (vector + texto nítido) |
| Retocar una foto de producto | **Photoshop** |
| Armar el manual de marca (PDF multipágina) | **InDesign** (o HTML→PDF, ver 99) |
| Diseñar una landing o app | **Figma** |
| Un post para Instagram, rápido | **Canva** |
| Un mockup (logo sobre una taza) | **Photoshop** o mockup online |
| Un moodboard | **Figma**, **Canva** o tablero físico |

## Sobre Figma (lo que cambió el juego)
Figma vive en el navegador, es colaborativo (varias personas a la vez, como un Google Docs del diseño) y se volvió el estándar para diseño de producto digital. Para Lushows: si en algún momento se diseña la web de la marca o una app, se hace en Figma. Para identidad de marca pura (logo, etiqueta), **Illustrator sigue mandando**.

## Sobre Canva (sin esnobismo)
Canva es legítimo para lo que es: velocidad y autonomía del no-diseñador. El problema no es Canva, es **usar Canva para lo que necesita Illustrator**: un logo hecho en Canva suele venir como PNG sin versión vectorial, sin variantes, sin control fino. Sirve para producir contenido del día a día *una vez que la marca ya existe* y tiene plantillas definidas.

Recomendación para Lushows: la **identidad** (logo, paleta, etiqueta madre) se hace bien en Illustrator. La **operación diaria** (posts, historias) puede vivir en Canva con plantillas derivadas de esa identidad.

## Flujo recomendado para un proyecto de marca

```
1. Investigación + concepto        → papel, notas, referencias
2. Moodboard                       → Figma / Canva / tablero
3. Bocetos de logo                 → papel y lápiz (sí, papel)
4. Digitalización del logo         → Illustrator (vector)
5. Sistema: paleta + tipografía    → Illustrator / Figma
6. Aplicaciones (etiqueta, tarjeta)→ Illustrator
7. Mockups en contexto             → Photoshop / mockup online
8. Manual de marca                 → InDesign o HTML→PDF (ver 99)
9. Entrega de archivos             → carpeta organizada (ver 93, 99)
```

## Herramientas gratis o económicas que sí valen
- **Inkscape** — alternativa libre a Illustrator (vector). Curva de aprendizaje, pero capaz.
- **GIMP** — alternativa libre a Photoshop.
- **Figma** — plan gratis muy generoso.
- **Photopea** — Photoshop en el navegador, gratis, abre archivos .PSD.

No son excusa para entregar mal, pero permiten empezar sin pagar suscripción.

## Errores comunes de herramienta
- Diseñar el logo en Photoshop (queda pixelado al ampliar) → **usa Illustrator**.
- Maquetar un catálogo de 20 páginas en Illustrator (se vuelve inmanejable) → **usa InDesign**.
- Hacer la etiqueta en Canva y mandarla a imprenta en PNG → **rechazo de la imprenta** (ver 92).
- Usar 5 herramientas distintas sin sistema → caos de archivos (ver 99 sobre entrega ordenada).

## Mini-checklist antes de empezar un encargo
- [ ] ¿Esto es vector (logo/ícono) o imagen (foto)? → define Illustrator vs Photoshop.
- [ ] ¿Es una sola pieza o un documento multipágina? → InDesign si es largo.
- [ ] ¿Necesito colaborar en vivo o es digital/web? → Figma.
- [ ] ¿Ya tengo la marca y solo produzco contenido? → Canva con plantillas.
- [ ] ¿El cliente podrá editarlo después? → planea formatos y handoff (ver 99).

**Siguiente paso:** define la tarea concreta primero, elige la herramienta segundo. Si dudas entre vector e imagen, lee 93. Si vas a imprimir, lee 92 antes de exportar nada.
