# 06 — Glosario contable para no técnicos

Los contadores hablan en un idioma propio. Este módulo es tu diccionario: cada término en lenguaje simple, con un ejemplo cuando ayuda. No necesitas memorizarlo; vuelve aquí cuando una palabra te trabe. Está ordenado de lo más básico a lo más específico de Colombia.

## Los cimientos

| Término | En simple |
|---|---|
| **Activo** | Lo que el negocio tiene (efectivo, equipos, inventario, lo que te deben) |
| **Pasivo** | Lo que el negocio debe a terceros (préstamos, proveedores, impuestos por pagar) |
| **Patrimonio** | Lo que realmente es tuyo: tus aportes + las ganancias acumuladas |
| **Ecuación contable** | Activo = Pasivo + Patrimonio. Siempre en equilibrio |
| **Ingreso** | Plata que el negocio gana por vender (no toda plata que entra es ingreso) |
| **Gasto / Costo** | Lo que el negocio consume para operar y vender |
| **Utilidad** | Ingresos − Gastos. Lo que sobra (o falta, si es pérdida) |

## La mecánica del registro

| Término | En simple |
|---|---|
| **Partida doble** | Cada hecho se anota en al menos dos cuentas; débitos = créditos |
| **Débito** | El lado izquierdo de una cuenta. NO significa "bueno" ni "entra plata" |
| **Crédito** | El lado derecho de una cuenta. NO significa "deuda" ni "sale plata" |
| **Asiento contable** | El registro de un hecho económico en partida doble |
| **Cuenta** | Una "cajita" donde se acumulan movimientos del mismo tipo (ej. Caja) |
| **Libro diario** | Todos los asientos en orden de fecha |
| **Libro mayor** | Cada cuenta con todos sus movimientos y su saldo |
| **Balance de comprobación** | Lista de todas las cuentas con saldos; sus débitos y créditos deben cuadrar |
| **Saldo** | El resultado neto de una cuenta tras sumar sus débitos y créditos |

## Conceptos de medición

| Término | En simple |
|---|---|
| **Devengo / causación** | Registrar cuando ocurre el hecho, no cuando entra la plata |
| **Base caja** | Registrar solo cuando entra o sale el dinero (más simple, menos preciso) |
| **Depreciación** | Repartir el costo de un activo (ej. un computador) a lo largo de su vida útil |
| **Amortización** | Como la depreciación, pero para activos intangibles (ej. una licencia) |
| **Provisión** | Reservar contablemente para un gasto futuro probable |
| **Valor razonable** | Lo que algo valdría hoy en el mercado |
| **Materialidad** | Si un error es tan pequeño que no cambia decisiones, se tolera |

## Reportes

| Término | En simple |
|---|---|
| **Estados financieros** | Los informes que cuentan la salud del negocio |
| **Balance general / Estado de situación financiera** | Foto de activos, pasivos y patrimonio en una fecha |
| **Estado de resultados** | Película de ingresos, gastos y utilidad en un periodo |
| **Flujo de efectivo** | De dónde entró y a dónde se fue la plata |
| **Conciliación** | Cruzar tus libros contra la realidad (ej. el extracto del banco) |
| **Cierre contable** | Cerrar el periodo: ajustar, conciliar y dejar los libros listos |

## Marcos y normas

| Término | En simple |
|---|---|
| **NIIF / IFRS** | El idioma contable estándar internacional |
| **NIIF para Pymes** | Versión simplificada para pequeñas y medianas empresas |
| **Grupos 1/2/3** | Clasificación colombiana por tamaño que define cuánto detalle reportas |
| **PUC** | Plan Único de Cuentas: el catálogo numerado de cuentas en Colombia |

## Colombia tributario y laboral

| Término | En simple |
|---|---|
| **DIAN** | La autoridad de impuestos nacional |
| **UVT** | Unidad de Valor Tributario: una "unidad de medida" para topes y sanciones; **su valor cambia cada año, verificar el vigente** |
| **IVA** | Impuesto al valor agregado que cobras en ciertas ventas |
| **Retención en la fuente** | Un adelanto del impuesto que se descuenta al pagar |
| **ICA** | Impuesto municipal sobre la actividad; tarifa por ciudad y actividad |
| **PILA** | Planilla con la que se paga la seguridad social de empleados |
| **Prestaciones sociales** | Cesantías, prima, vacaciones e intereses que se deben al empleado |
| **Exógena** | Información que se reporta a la DIAN cada año sobre terceros |
| **Formato 2516** | Conciliación entre la utilidad contable (NIIF) y la fiscal (renta) |
| **Factura electrónica** | Factura validada por la DIAN en formato digital |

## Errores comunes

- **Creer que débito = entra y crédito = sale.** No: depende de la naturaleza de la cuenta (módulo 02).
- **Confundir ingreso con "plata que entró".** Un préstamo entra pero no es ingreso, es pasivo.
- **Tratar la UVT como un valor fijo.** Cambia cada año.
- **Mezclar utilidad con efectivo.** Puedes tener utilidad y no tener plata en el banco (por eso existe el flujo de efectivo).
