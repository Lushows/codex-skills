# 88 — El flujo de trabajo contable mensual, paso a paso

La contabilidad no es una tarea de "fin de año": es un **ritmo mensual**. Cuando cada mes se cierra bien, el cierre anual y las declaraciones salen casi solos. Cuando se deja todo "para después", llega el caos de diciembre. Este módulo es la **rutina del mes** con herramientas: qué hacer, en qué orden y con qué software, para que el negocio siempre tenga sus números al día.

Es una guía para todo público: el dueño puede seguirla para entender qué pasa, y el contador para no saltarse un paso.

> **Cada mes cuadra, cumple y queda auditable.** Si el mes cierra cuadrado y con soportes, no hay sustos en la declaración. La automatización ayuda en cada paso, pero el cierre lo **revisa y aprueba una persona**.

## Términos que debes conocer
- **Cierre del mes:** dejar el mes "terminado": todo registrado, conciliado y cuadrado.
- **Balance de prueba:** lista de cuentas con su saldo; debe cuadrar (débitos = créditos).
- **Devengo:** registrar el gasto/ingreso cuando ocurre, aunque el pago sea después.
- **Periodicidad de impuestos:** algunos son mensuales, otros bimestrales, otros anuales (ver bloque 40).

## El flujo del mes, paso a paso
| Paso | Qué se hace | Herramienta |
|---|---|---|
| 1. Capturar | Recoger todas las facturas de venta y de compra del mes | OCR / bot WhatsApp (85, 86) |
| 2. Registrar | Asentar ingresos, gastos, nómina en partida doble | Software contable / Excel (12, 80) |
| 3. Conciliar bancos | Cargar extractos y cuadrar saldo libro vs. banco | Conciliación (83) |
| 4. Revisar IVA/retención | Verificar impuestos del periodo si aplica | Bloque 40–43 |
| 5. Nómina y PILA | Liquidar sueldos, seguridad social y prestaciones | Software de nómina |
| 6. Cuadrar | Sacar el balance de prueba y confirmar que cuadra | Software / Excel (89) |
| 7. Estados financieros | Generar balance y estado de resultados del mes | Software (20, 21) |
| 8. Respaldar | Backup de todo + guardar soportes | Respaldos (87) |
| 9. Revisar e informar | El humano revisa, explica y entrega al dueño | Control humano |

## Una agenda mensual realista
- **Durante el mes (continuo):** capturar facturas apenas llegan (no acumular). El bot/OCR ayuda.
- **Primeros días del mes siguiente:** descargar extractos, registrar lo pendiente, conciliar.
- **Hacia la mitad:** cuadrar, sacar estados financieros, revisar impuestos del periodo.
- **Según calendario DIAN:** presentar y pagar lo que venza (IVA, retención, etc. — ver bloque 40).
- **Antes de cerrar:** respaldar y dejar todo soportado.

## Ejemplo (cifras ILUSTRATIVAS / inventadas)
"Restaurante La Fonda" cierra abril así: capturó 60 facturas por el bot durante el mes; en los primeros 5 días de mayo registró lo pendiente y concilió 2 bancos (apareció una comisión de $35.000 sin registrar, se ajustó); cuadró el balance de prueba (débitos = créditos); generó el estado de resultados (utilidad del mes); revisó el impuesto al consumo; respaldó todo en la nube. El dueño recibió un informe de 1 página. (Cifras inventadas; cuadres verificados en `Matematicas_lushows`.)

## Buenas prácticas
- **No acumules captura:** una factura del día se registra fácil; 200 a fin de mes, no.
- **Concilia siempre antes de cuadrar:** un banco descuadrado arruina los estados financieros.
- **Ten una lista de chequeo** (los 9 pasos) y márcala cada mes.
- **Cierra el mes y "ciérralo de verdad":** evita reabrir meses ya cerrados sin justificación.

## Errores comunes
- Dejar todo para fin de mes/año → errores, prisa y declaraciones mal hechas.
- Sacar estados financieros **sin** conciliar bancos → cifras irreales.
- Saltarse el respaldo del cierre → si algo falla, se pierde el mes.
- No revisar el calendario tributario → vencimientos perdidos y sanciones.
