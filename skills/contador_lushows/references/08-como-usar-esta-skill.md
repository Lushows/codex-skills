# 08 — Cómo usar esta skill (mapa necesidad → módulo)

Esta skill tiene muchos módulos. No los leas todos de corrido: carga solo el que tu necesidad pide en el momento. Este módulo es el índice inteligente que traduce "lo que el usuario quiere" en "qué módulo abrir". Piénsalo como el directorio de un edificio: te dice en qué piso está cada cosa.

## Cómo empezar siempre

1. Si es el primer contacto con un negocio nuevo → **módulo 05 (diagnóstico)**. Sin perfil, no hay registro correcto.
2. Si el usuario no entiende un término → **módulo 06 (glosario)**.
3. Si la pregunta es de decisión, cálculo exacto o el bot → **módulo 07 (ruteo)** y deriva.
4. Si es trabajo contable concreto → busca en el mapa de abajo.

## Mapa necesidad → módulo (Bloque 0: fundamentos)

| Lo que el usuario dice o necesita | Módulo a cargar |
|---|---|
| "Quiero entender cómo trabaja un contador" | 00 — método |
| "¿Qué me garantizas exactamente?" | 01 — promesa (cuadre/cumplimiento/auditable) |
| "Explícame débito y crédito / cómo se anota" | 02 — ecuación y partida doble |
| "¿Qué son las NIIF? ¿Cuáles me aplican?" | 03 — marco normativo |
| "¿Es legal hacer esto? ¿Hay conflicto de interés?" | 04 — ética y secreto profesional |
| "Empecemos de cero con mi negocio" | 05 — diagnóstico inicial |
| "No entiendo esta palabra contable" | 06 — glosario |
| "¿Esto lo haces tú u otra skill?" | 07 — ruteo al equipo |
| "¿Por dónde empiezo?" | 08 — este mapa |
| "¿Hasta dónde llega tu responsabilidad?" | 09 — disclaimers y responsabilidad |

> Nota: este Bloque 0 son los fundamentos. Los módulos de registro práctico, estados financieros, impuestos colombianos (IVA, retención, ICA), nómina/PILA, conciliación y cierre viven en bloques posteriores de la skill y se cargan cuando el trabajo lo pide.

## Regla de oro: cargar poco, en el momento justo

No abras cinco módulos "por si acaso". Carga el que necesitas, resuélvelo, y avanza. Esto mantiene el trabajo enfocado y barato en tokens. Si dudas cuál cargar, vuelve a este mapa.

## Ejemplo de uso (caso ILUSTRATIVO / inventado)

> Usuario: "Tengo un negocio nuevo, vendo un Excel por internet, no sé nada de contabilidad y quiero llevar mis números bien."

Ruta sugerida:
1. **Módulo 05** — diagnóstico (país, forma, régimen, grupo NIIF, software, necesidad).
2. **Módulo 06** — glosario, cada vez que aparezca una palabra nueva.
3. **Módulo 02** — para que entienda cómo se registran sus ventas.
4. Luego, los módulos de registro práctico e impuestos según lo que el diagnóstico revele.

Datos del ejemplo inventados para ilustrar el recorrido.

## Combos frecuentes

| Situación | Módulos en orden |
|---|---|
| Arranque desde cero | 05 → 06 → 02 → (registro práctico) |
| "Explícame qué garantizas" | 01 → 04 → 09 |
| "Quiero aprender la base" | 00 → 02 → 06 |
| "No sé si esto es contable o decisión" | 07 (y deriva si aplica) |

## Errores comunes

- **Leer todos los módulos antes de empezar.** Abruma y gasta tokens; carga bajo demanda.
- **Saltarse el diagnóstico (05)** y aplicar una receta que no encaja.
- **No usar el glosario (06)** y seguir adelante con términos que el usuario no entendió.
- **Intentar resolver en el contador lo que es decisión o cálculo** en vez de rutear (07).

## Conexión con otros módulos

- El diagnóstico que casi siempre va primero es el módulo **05**.
- El ruteo a otras skills está en el **07**.
- Los límites de lo que esta skill puede hacer están en el **09**.

## Siguiente paso típico

Identifica la necesidad del usuario, ubícala en el mapa, y abre ese módulo. Si es un negocio nuevo, casi siempre empiezas por el **05**.
